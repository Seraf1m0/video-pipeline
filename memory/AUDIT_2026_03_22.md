## 2. Модули — что делает каждый

### assembler.py

Главный монтажный агент. Принимает `--channel` и `--session`, оркестрирует весь конвейер.

**Входные данные:**
- `data/channels/{lang}/{session}/input/*.mp3` — озвучка диктора
- `data/channels/{lang}/{session}/transcripts/result.json` — JSON сегментов с таймингами
- `data/channels/{lang}/{session}/intro.mp4` — готовое интро
- `library/clips/*.mp4` — клипы библиотеки (при `--use-library`)

**Выходные данные:**
- `output/{session}_{LANG}_final.mp4` — финальное видео с субтитрами, аудио, цветокоррекцией
- `output/mixed_audio.aac` — финальный аудио-микс
- `transcripts/subtitles_animated.ass` — ASS субтитры

**Параметры CLI:**
```
--channel channel_001_cosmos_de    # выбор канала
--session Video_20260305_222350    # конкретная сессия
--no-subs                          # без субтитров
--no-music                         # без фоновой музыки
--use-library                      # использовать библиотеку клипов
--intro-duration 90                # длина интро в секундах (default 90)
--skip-intro-clips                 # не генерировать intro_clips/
```

**Основной флоу:**
1. Определить канал → загрузить стиль из `channel_styles.json`
2. Найти последнюю сессию → загрузить сегменты из `result.json`
3. Найти озвучку → запустить `silencedetect` для rhythm-aware timing
4. Найти `intro.mp4` → взять `ffprobe` длительность
5. Подобрать клипы из библиотеки (`resolve_library_clips` + `ClipSelector`)
6. Нарезать клипы пропорционально словам (`prepare_trimmed_clips`, 8 потоков)
7. Построить per-boundary transition sequence (`_build_trans_sequence`)
   - Rhythm-based duration (silence-aware)
   - 5% flash frames (fadewhite/fadeblack/fade)
   - 10% cross_zoom variety для FR канала
   - Anticipation shift — сдвиг переходов перед паузами
8. **Параллельно** (2 потока): генерация ASS субтитров + склейка клипов с переходами
9. Подготовить аудио: озвучка → музыка → финальный микс → SFX inject
10. Соединить интро + видеоряд через intro_transition_fn (smooth_zoom / whip_pan)
11. Паддинг если видео короче озвучки (freeze last frame)
12. Финальный FFmpeg: цветокоррекция + ASS субтитры + аудио + Adobe metadata → final.mp4

**Ключевые константы:**
- `MUSIC_START_SEC = 88.0` — музыка стартует на 1:28
- `VOICEOVER_DB = -6.0` / `INTRO_AUDIO_DB = -37.0` / `MUSIC_DB = -22.0`
- Цветокоррекция включается с `t=90s` (`enable='gte(t,90)'`)
- Метаданные: фиктивные Adobe Premiere/Media Encoder (7 вариантов)

**Зависимости:** transitions.py, sfx_mixer.py, audio_mixer.py, ass_generator.py,
subtitle_burner.py, style_engine.py, paths.py, channel_manager.py, `agents/library/clip_selector.py`

### transitions.py

FFmpeg-переходы. Два уровня: intro→main и clip-clip.

**Intro→main переходы:**

| Функция | Канал | Метод | Параметры |
|---|---|---|---|
| `smooth_zoom_transition` | DE | scale 1.05x + gblur σ=28 ramp up/down + dissolve | duration=0.32s |
| `whip_pan_transition` | FR | boxblur luma_radius=60 ramp + dissolve + overshoot 3кадра | duration=0.20s |
| `intro_to_main_transition` | fallback | gblur σ=30 ramp + dissolve | duration=0.75s |

**Замечание:** `zoompan` и `slideleft` удалены полностью. Оба используют `_blur_ramp_zone` (sin/cos weighting через blend).

**Clip-clip переходы (`concat_all_with_transitions`):**

| Тип | xfade | Пре-обработка |
|---|---|---|
| `cross_zoom` | dissolve | gblur σ=18 в зонах перехода через `enable=` |
| `glitch_flash` | fadeblack | 50% → rgbashift ±10px R/B; 50% → plain fadeblack |
| `glitch_chroma` | fadeblack | то же (внутренний маркер) |
| `dissolve` | dissolve | нет |
| `fadewhite` | fadewhite | нет (flash frame) |
| `fadeblack` | fadeblack | нет (flash frame) |
| `fade` | fade | нет (flash frame) |

**Важно: `pixelize` в `_XFADE_MAP` отсутствует.** `cross_zoom` маппится на `dissolve`, не на `pixelize`. Функция `prepend_intro` в `assembler.py` (legacy path) использует `pixelize` — это единственное место, где он остался.

Chunk-based обработка: при >20 клипах разбивает на чанки по 20, обрабатывает параллельно (8 потоков для `get_video_duration`).

**Legacy алиасы:** `slide_transition`, `glitch_transition`, `slide_motionblur_transition`, `simple_slide` — оставлены для обратной совместимости.

**Зависимости:** `ffmpeg`, `ffprobe`, `subprocess`, `ThreadPoolExecutor`

### sfx_mixer.py

Инжект SFX в аудио на временных метках переходов.

**Входные данные:**
- `audio_path` — готовый аудиофайл (mixed_audio.aac)
- `transition_times` — список временных меток (секунды)
- `transition_types` — список типов переходов (опционально)
- `sfx_enabled`, `whoosh_chance`, `channel_id`

**Выходные данные:**
- Новый аудиофайл с наложенными SFX (или оригинал при ошибке/пустом пуле)

**Логика `_build_sfx_events`:**

| Тип перехода | Первичный SFX | Вероятность | Вторичный SFX |
|---|---|---|---|
| `glitch_flash` | glitch (если есть) | 100% | нет |
| каждый 5-й (is_strong) | impact (-14 dB) | 100% | whoosh×0.35 (40%) |
| `smooth_zoom` | whoosh (-20 dB) | 70% | нет |
| `whip_pan` | whoosh (-20 dB) | 90% | tail +80ms×0.45 (30%) |
| `cross_zoom` | whoosh (-20 dB) | 40% | нет |
| `fadewhite/fadeblack/fade` | нет | — | нет (flash_frame skip) |

Если `assets/sfx/` пустой → graceful fallback, возвращает оригинальный аудиофайл.

Инжект через `ffmpeg filter_complex`: `adelay` + `volume` + `amix`.

### media_generator.py

Роутер платформ генерации медиа.

**Платформы:**
- `1` = Google Flow (браузер CDP + cookies)
- `2` = Grok (браузер CDP, SuperGrok, image-to-video)
- `3` = PixelAgent API (`POST voiceapi.csv666.ru/api/v1/image/create`)

**Режимы запуска:**

- `--platform 3 --type photo` — из бота
- `--regenerate N` — перегенерировать конкретное видео (убирает из прогресса, перезапускает)
- `--streaming` — параллельный режим: 7 потоков фото (v1×4 + v2×3) → Grok видео

**Выходные данные:**
- `data/media/{session}/photos/photo_NNN.png`
- `data/media/{session}/videos/video_NNN.mp4`

**Зависимости:** `grok_agent.py`, `pixel_agent.py`, `flow_agent.py`, `utils.py`, CDP Chrome

### prompt_generator.py

Батчевая генерация промптов через Claude CLI (`claude.exe`).

**Входные данные:**
- `data/transcripts/{session}/result.json` — сегменты с текстом
- `config/master_prompts/photo/*.txt` — мастер-промпт для фото
- `config/master_prompts/video/*.txt` — мастер-промпт для видео

**Выходные данные:**
- `data/prompts/{session}/photo/photo_prompts.json` — список `{photo_prompt, negative_prompt}`
- `data/prompts/{session}/video_prompts.txt` — промпты разделены `\n\n`

**Параметры:**
```
--type photo|video|both
--photo-master photo_master_prompt_de.txt
--video-master master_video_grok.txt
--photo-platform gemini|flow|grok  (default: gemini)
--video-platform grok|flow          (default: grok)
--project Video_20260227_220628
```

**Логика:**
1. Загружает контекст активного канала (`source_language`, `niche`)
2. Делит сегменты на батчи по 10
3. Запускает до 5 параллельных потоков (`ThreadPoolExecutor`)
4. Каждый батч → `claude -p "..."` (subprocess, без `CLAUDECODE` env var)
5. Парсит ответ по паттерну `SEGMENT N`
6. Сохраняет прогресс в `temp/prompt_progress.json`

**Claude CLI:** `%APPDATA%/Claude/claude-code/{latest_version}/claude.exe`, добавляется в PATH автоматически.

## 4. Что работает

- **Полный монтажный пайплайн** (assembler.py): загрузка → клипы → переходы → аудио-микс → субтитры → финальный экспорт — работает end-to-end
- **Rhythm-based timing**: `silencedetect` + `_adaptive_trans_dur` + `_apply_anticipation` — полностью реализованы
- **Per-boundary transition sequence**: `_build_trans_sequence` — flash frames (5%), FR variety (10% cross_zoom), micro-variance ±8%
- **smooth_zoom_transition** (DE): scale 1.05x + gblur σ=28 + blend ramp + dissolve — без zoompan артефактов
- **whip_pan_transition** (FR): boxblur luma_radius=60 + blend ramp + dissolve + adaptive overshoot 34–42px
- **SFX инжект** (sfx_mixer.py): контекстный выбор по типу перехода, вторичные слои (impact+whoosh, whip_pan tail), graceful fallback если нет SFX-файлов
- **GPU энкодер** (NVENC h264_nvenc): автодетекция + CPU fallback везде
- **ASS субтитры** (ass_generator.py + subtitle_burner.py): Organetto font, fade, rise анимации
- **Chunk-based xfade**: при >20 клипов автоматически разбивает на чанки по 20
- **Параллельная обрезка клипов**: 8 потоков ThreadPoolExecutor
- **Паддинг видео**: если видео короче озвучки — freeze last frame (tpad)
- **Adobe metadata spoofing**: 7 вариантов encoder/software/creation_time
- **PixelAgent API**: фото через `POST voiceapi.csv666.ru`, X-API-Key auth, base64 response
- **Prompt Generator**: батчи по 10, 5 параллельных Claude CLI subprocess
- **Telegram Bot**: полная управляющая панель со всеми этапами пайплайна
- **Channel Manager**: активный канал, конфиги DE/FR
- **paths.py**: централизованные пути под новую структуру `data/channels/{lang}/{session}/`

## 5. Что сломано / проблемы

- **`color_grade` поле игнорируется**: `channel_styles.json` содержит `color_grade: "warm_cinematic"` для DE и `"cool_cinematic"` для FR, но `assembler.py` применяет одну и ту же `warm_cinematic` цветокоррекцию для обоих каналов. Разветвления по `color_grade` в коде нет.

- **`prepend_intro` использует `pixelize`**: функция `prepend_intro()` в assembler.py (строка ~716) содержит `xfade=transition=pixelize` — это legacy-код, который вызывается только если интро+сцены склеиваются старым методом. Основной флоу использует `_intro_trans_fn` (smooth_zoom/whip_pan). Риск: если основной путь упадёт и сработает fallback в `prepend_intro`, `pixelize` будет вызван через xfade — он работает, но визуально не соответствует новому стилю.

- **`video_validator.py` ищет старый путь**: использует `_get_channel_base(channel_id) / "data" / "media"` вместо новой структуры `data/channels/{lang}/{session}`. Вероятно не находит сессии при новой схеме путей.

- **`assets/sfx/` папка отсутствует**: SFX инжект включён для FR канала (`sfx_enabled: true`), но папки `assets/sfx/whoosh/`, `assets/sfx/impact/`, `assets/sfx/glitch/` не видны в дереве проекта. sfx_mixer.py имеет graceful fallback (возвращает оригинальный аудиофайл), но SFX фактически не работают.

- **`active_channel.json` дублируется**: есть `config/active_channel.json` и `bot/active_channel.json`. `channel_manager.py` использует `bot/active_channel.json`. Файл в `config/` — лишний (или использовался старым кодом).

- **`pipeline.py` устарел**: содержит только вызов `transcriber.run()`, остальные шаги не подключены. Полный пайплайн управляется через Telegram Bot.

- **`MUSIC_DIR` в `.env`**: указан путь `C:\Users\Serafim\Music\background`, но `audio_mixer.py` и `assembler.py` берут его из `os.getenv("MUSIC_DIR")`. Если папка не существует — музыка тихо пропускается. Нет явной ошибки.

- **`subtitle_generator.py` (legacy)**: `assembler.py` вызывает `generate_ass` напрямую, `SUBTITLE_SCRIPT` (subtitle_generator.py) вызывается в `generate_subtitles()`, которая в коде объявлена но не вызывается из основного `main()`. Фактически используется `ass_generator.py`.

- **`clip_selector`**: assembler.py импортирует `from clip_selector import select_clips_for_video`, ищет в `agents/library/`. Папка `agents/library/` пуста (нет `clip_selector.py`). `_LIBRARY_OK` становится `False`, `resolve_library_clips` возвращает оригинальный `clips_dir` — то есть клипы берутся из `output/temp/lib_clips/` которая обычно пуста. Это означает что без `--use-library` и без готовой папки клипов ассемблер получит 0 клипов.

- **Дублирование `get_session_dir`**: `paths.py` экспортирует функцию, но в `assembler.py` нет её явного импорта (не в списке import из paths). Используется как `get_session_dir(channel_id, session)` в `find_intro` — работает только потому что функция добавлена в глобальный namespace через `from paths import ...` неявно.

## 7. Флоу данных

```
[MP3 озвучка]
     │
     ▼
1. transcriber.py
   → data/channels/{lang}/{session}/transcripts/result.json
      {segments: [{id, start, end, text}], total_duration}
     │
     ▼
2. prompt_generator.py  (Claude CLI subprocess, батчи по 10)
   → data/prompts/{session}/photo/photo_prompts.json
   → data/prompts/{session}/video_prompts.txt
     │
     ▼
3. media_generator.py (роутер)
   ├── pixel_agent.py  → data/media/{session}/photos/photo_NNN.png
   └── grok_agent.py   → data/media/{session}/videos/video_NNN.mp4
     │
     ▼
4. video_cutter.py  (нарезка на клипы)
   → data/channels/{lang}/{session}/clips/clip_NNN.mp4  (или library/)
     │
     ▼
5. assembler.py
   │
   ├─ [Rhythm analysis]  silencedetect → silence_regions
   ├─ [Clip selection]   ClipSelector (library/) → lib_clips/
   ├─ [Clip trim]        prepare_trimmed_clips (8 потоков) → temp/trimmed_NNN.mp4
   ├─ [Trans sequence]   _build_trans_sequence → [{type, dur}, ...]
   │
   ├─ [PARALLEL]
   │   ├─ ass_generator.py → transcripts/subtitles_animated.ass
   │   └─ concat_all_with_transitions → temp/videotrack.mp4
   │
   ├─ [Audio]
   │   ├─ prepare_voice_track → voice_track.aac
   │   ├─ prepare_music_track → music_track.aac
   │   ├─ final_mix           → mixed_audio.aac
   │   └─ inject_sfx (FR only) → mixed_audio_sfx.aac
   │
   ├─ [Intro join]  intro_transition_fn(intro.mp4, videotrack.mp4)
   │                → video_with_intro.mp4
   │                  DE: smooth_zoom_transition
   │                  FR: whip_pan_transition
   │
   └─ [Final export]  FFmpeg: video_with_intro + mixed_audio
                       + -vf "цветокоррекция,ass субтитры"
                       + h264_nvenc + Adobe metadata
                       → output/{session}_{LANG}_final.mp4
```
